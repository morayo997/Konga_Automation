**Konga Automation Project**

**Project Overview**
This project focuses on automating the shopping and checkout process on the Konga website using Selenium IDE.

**Project Objective**
To verify that an existing customer can sign in, navigate to the Apple MacBooks category, add a product to the cart, proceed to checkout, and verify the error message displayed when invalid card details are entered.

**Scope of Testing**
The automation covers the following:
. Open the Konga website
. Sign in as an existing customer
. Product category navigation
. Apple MacBooks selection
. Adding a product to the cart
. Selecting a delivery address
. Proceeding to payment
. Selecting card payment
. Entering invalid card details
. Verifying the Invalid card number error message

**Tools and Technologies**
. Selenium IDE
. Firefox
. GitHub

**Expected Result**
The system should display the appropriate error message when invalid card details are entered.
